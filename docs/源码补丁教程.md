# 源码补丁使用教程

`patches/0001-diting-0.5.0.patch` 是相对 **kirklin/skyward v0.5.0** 的补丁，把 diting 分支的
WLAN 预热、已保存网络、45 秒接口等待等改动移植到 0.5.0 上，并适配了 0.5.0 的 15 语言文本框架。

## 一、最省事：用 setup.sh

```bash
git clone https://github.com/nimazhale741/skyward-zeus.git
cd skyward-zeus
./scripts/setup.sh            # 默认拉 kirklin v0.5.0 并打补丁
```

成功后得到 `upstream/`，里面已经放好 `devices/zeus.toml` 并应用了补丁。

## 二、手动打补丁

```bash
git clone --depth 1 --branch v0.5.0 https://github.com/kirklin/skyward.git upstream
cd upstream
cp ../devices/zeus.toml devices/
git apply ../patches/0001-diting-0.5.0.patch
```

`git apply --check ../patches/0001-diting-0.5.0.patch` 先试一下，报错说明上游版本不对（必须是 v0.5.0）。

## 三、编译

```bash
cd upstream
export PATH="$HOME/.cargo/bin:$PATH"
export ANDROID_NDK_HOME=/opt/android-ndk-r28c        # 换成你的 NDK 路径

# 主程序（动态链接，recovery 里有 vendor 库）
cargo ndk -t arm64-v8a --platform 30 build --release -p skyward

# system-init（静态，装第二个系统时用）
RUSTFLAGS="-C target-feature=+crt-static" \
  cargo ndk -t arm64-v8a --platform 30 build --release \
  -p skyward-system-init --target-dir target/system-init

# 打包器（在电脑上跑）
cargo build --release -p skyward-pack
```

## 四、打包镜像

```bash
cd ..
cp /path/to/官方recovery.img ../stock-recovery.img     # 100 MiB 整块
cp /path/to/aw8697_haptic.bin ../aw8697_haptic.bin     # 震动固件
STOCK=../stock-recovery.img FIRMWARE=../aw8697_haptic.bin \
  ./scripts/pack-zeus.sh out/skyward-zeus.img
```

或一键：

```bash
./scripts/release-zeus.sh v0.5.0 OS4.0.0.44.XPBCNXM
```

## 五、验证

- 镜像大小必须 **104,857,600** 字节；
- `skyward-pack cat <img> system/bin/recovery | sha256sum` 应等于编译出的二进制；
- 刷入后 recovery 里 `dmesg | head` 应看到 `skyward: zeus 0.5.0 recovery up`。

## 六、常见错误

| 现象 | 原因/处理 |
| --- | --- |
| `git apply` 报 `patch does not apply` | 上游不是 v0.5.0；`git log -1` 确认 tag |
| `cargo ndk` 报找不到 target | `rustup target add aarch64-linux-android`（toolchain 1.100.0） |
| 链接报 `libdl.a ... Invalid record` | 在 Windows 上编 system-init 的已知问题；用 Linux 编，或给 NDK 换一个 `libdl.a` 存根 |
| 镜像不是 104857600 字节 | 基底 recovery.img 不对（必须 zeus 的 100 MiB 整块） |
| 刷完开不了机 | 先 `fastboot set_active a`；仍不行刷回备份 |

## 七、这个补丁到底改了什么

- `crates/skyward/src/wlan.rs`：`INTERFACE_WAIT` 20 s → 45 s（等 11 秒 DMS + 校准）
- `crates/skyward/src/wlan.rs` + `main.rs`：`prewarm`（开机后台预热芯片）
- `crates/skyward-net/src/saved.rs`（新文件）、`supplicant.rs`：已保存网络与自动连接
- `crates/skyward-ui/src/...`：Wi-Fi 页的“已保存网络”区块与“忘记网络”
- `crates/skyward-ui/locales/*.toml`：15 种语言补 `saved` 词条
- `crates/skyward-net/src/github.rs`：更新源指向本仓库
