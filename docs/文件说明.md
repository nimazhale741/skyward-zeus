# 文件说明：每个文件是干什么的

## 一、release 里的文件（下载后拿到的）

| 文件 | 大小 | 干什么用 | 刷到哪里 | 风险 |
| --- | --- | --- | --- | --- |
| `skyward-v0.5.0-zeus.img` | 104,857,600 B（100 MiB） | Skyward v0.5.0 recovery 整块镜像 | **只能** `recovery_a` | 刷错分区会开不了机 |
| `skyward-v0.5.0-zeus-OS4.0.0.44.XPBCNXM.zip` | 约 46 MB | 同上的 zip，给 recovery 里“更新 Skyward”用 | 不刷，放手机里 | 无 |
| `0001-diting-0.5.0.patch` | 135 KB | 源码补丁：把 diting 的 WLAN 功能移植到上游 v0.5.0 | 不刷，编译用 | 无 |
| `SHA256SUMS` | 几百字节 | 上面文件的 SHA-256 校验值 | 不刷 | 无 |

> **release 里没有 vendor_boot 镜像。** 那个和系统版本绑定，跨版本刷会出问题；
> 需要修 WLAN 11 秒的人，用 `tools/patch_vendor_boot.py` 打自己机器的（见 `vendor_boot补丁教程.md`）。

### 两个 img 别搞混

- `recovery_a` 分区 = **100 MiB** → 刷 `skyward-v0.5.0-zeus.img`
- `vendor_boot_a` 分区 = **96 MiB** → 刷自己打出来的 `vendor_boot-dmsfix.img`
- 分区大小不一样，刷错会直接失败或开不了机；不确定就 `fastboot getvar partition-size:<名字>`。

## 二、仓库里的文件（想编译/想改才用）

| 文件 | 干什么用 |
| --- | --- |
| `devices/zeus.toml` | 设备配置：屏幕、触摸、震动、WLAN 模块/固件、预热、已保存网络、服务 |
| `patches/0001-diting-0.5.0.patch` | 相对 `kirklin/skyward v0.5.0` 的源码补丁（预热、已保存网络、45 s 等待、15 语言适配） |
| `scripts/setup.sh` | 拉上游 v0.5.0、放 `devices/zeus.toml`、应用补丁，得到能编译的 `upstream/` |
| `scripts/pack-zeus.sh` | 用编译产物 + 官方 recovery 基底打 100 MiB 镜像 |
| `scripts/release-zeus.sh` | 编译 + 打包 + 压 zip + 打印 SHA-256（可选 gh 发布） |
| `tools/patch_vendor_boot.py` | 给**自己手机 dump 的** vendor_boot 打 cnss2 补丁（修 11 秒） |
| `docs/源码补丁教程.md` | 补丁怎么用、怎么编、常见错误 |
| `docs/vendor_boot补丁教程.md` | vendor_boot 补丁怎么打、怎么刷、怎么回滚 |
| `docs/WLAN-DMS修复.md` | 为什么会有那 11 秒、补丁改了哪 4 个字节 |
| `docs/刷入简易说明.md` | 最短的刷入步骤 |

## 三、我只想用，不想编译

1. 下 `skyward-v0.5.0-zeus.img`；
2. 备份自己的 `recovery_a`；
3. `fastboot flash recovery_a` 刷入；
4. 想 WiFi 快，再按 `vendor_boot补丁教程.md` 给自己机器打 vendor_boot 补丁。

## 四、我想自己编译

看 `源码补丁教程.md`。需要 Linux（或 WSL）、Rust 1.100、cargo-ndk、Android NDK r28。
