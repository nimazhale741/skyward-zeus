# Skyward for 小米 12 Pro（zeus）· 刷入说明

## 这份是什么

- `skyward-v0.5.0-zeus.img`：Skyward v0.5.0 移植版，整块 100 MiB recovery 分区镜像，只刷 `recovery_a`。
- `vendor_boot-v0.5.0-zeus-OS4.0.0.44.XPBCNXM.img`：修 WLAN 11 秒等待的 vendor_boot，刷 `vendor_boot_a`。
  **只匹配 OS4.0.0.44.XPBCNXM**，系统版本不同不要刷。

## 刷前备份（recovery 里 root adb 即可）

```bash
dd if=/dev/block/by-name/recovery_a    of=/sdcard/recovery-backup.img bs=1M
dd if=/dev/block/by-name/vendor_boot_a of=/sdcard/vendor_boot-backup.img bs=1M
```

## 刷入（电脑 fastboot）

```powershell
adb reboot bootloader
fastboot flash recovery_a    "skyward-v0.5.0-zeus.img"
fastboot flash vendor_boot_a "vendor_boot-v0.5.0-zeus-OS4.0.0.44.XPBCNXM.img"
fastboot set_active a
fastboot reboot
# 等约 35 秒系统起来后
adb reboot recovery
```

## 刷完自检（recovery 里 adb 直连就是 root）

```bash
cat /proc/uptime
dmesg | grep -E "DMS QMI|wlan_mac.bin|ahead of its switch"
ls /sys/class/net | grep wlan0
ifconfig wlan0
```

正常表现：

- `cnss: DMS QMI connection not established` 只有 2 行（原来 201 行）
- `t≈14.3s`：`Unable to get MAC from DMS after retries` → 立刻 `using MAC address from wlan_mac.bin`
- `t≈14.9s`：`skyward: the WLAN's chip is up ahead of its switch`
- `t≈15s`：`wlan0` 有 IP、有默认路由

只刷 recovery 不刷 vendor_boot 时，上面时间点整体晚约 11 秒。

## 回退

```powershell
fastboot flash recovery_a    "recovery-backup.img"
fastboot flash vendor_boot_a "vendor_boot-backup.img"
```

## 已知行为

- WLAN 页初始为“关”，点开 1~2 秒出列表。
- 触摸固件 `st_fts_l2.ftb` 未打包：自动更新失败两次，触摸正常。
- `aw8697_rtp_1.bin` 缺失：只影响 RTP 音效。
- 系统 OTA 会覆盖 vendor_boot 补丁，升级后重刷一次即可。
