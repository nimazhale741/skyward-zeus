# Skyward for 小米 12 Pro（zeus）· 刷入说明（最短版）

> 每个文件是干什么的、该刷哪个：先看 `文件说明.md`。
> 想修 WLAN 11 秒：看 `vendor_boot补丁教程.md`。

## 1. 备份

recovery 里（adb 直连就是 root）：

```bash
dd if=/dev/block/by-name/recovery_a of=/sdcard/recovery-backup.img bs=1M
```

## 2. 刷 recovery

```powershell
adb reboot bootloader
fastboot flash recovery_a "skyward-v0.5.0-zeus.img"
fastboot set_active a
fastboot reboot
# 等约 35 秒系统起来后
adb reboot recovery
```

## 3. 可选：修 WLAN 11 秒

按 `vendor_boot补丁教程.md`：dump 自己机器的 vendor_boot → `tools/patch_vendor_boot.py`
→ 刷回 `vendor_boot_a`。**不要刷别人的 vendor_boot。**

## 4. 验证

```bash
dmesg | grep -E "recovery up|DMS QMI|ahead of its switch"
```

- `skyward: zeus 0.5.0 recovery up`
- 没打 vendor_boot 补丁：DMS 201 行，约 28 秒 WiFi 可用
- 打了：DMS 2 行，约 15 秒 WiFi 可用

## 回退

```powershell
fastboot flash recovery_a "recovery-backup.img"
```

## 刷完 recovery 后进 recovery 的节奏

`fastboot flash recovery_a` 写完不要立刻敲重启命令，**等约 15 秒**再执行：

```powershell
fastboot reboot recovery
```

这台机器的 bootloader 有时会忽略 `recovery` 参数；如果等 15 秒后仍进了系统，就退回：

```powershell
fastboot reboot
# 等约 35 秒系统起来
adb reboot recovery
```

或试 `fastboot oem reboot-recovery`（部分小米机型支持，不支持会报 unknown command，无副作用）。
