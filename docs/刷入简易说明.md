# Skyward for 小米 12 Pro（zeus）· 刷入简易说明

## 这份是什么

`skyward-zeus-v6.img` —— 小米 12 Pro 的第三方 Recovery（Skyward v0.3.1 移植版），
整块 100 MiB recovery 分区镜像，**只能刷进 `recovery_a`**，不碰系统、不碰数据。

- 大小：104,857,600 B（=102400 KB，必须整块，不能裁）
- SHA-256：`1698da2c3a5eb2b09ea19d9684c100d7a5f5d02d8af57242a5ebdc7333b28a8a`

## 手机上下载后怎么刷（要在电脑上操作）

1. 把 `skyward-zeus-v6.img` 从手机传回电脑（数据线 / 微信文件传输都行），放任意目录
2. 电脑上打开命令行，手机连好 USB，确认认得设备：

```powershell
adb devices            # 应看到 e61abf85   device
```

3. 进 bootloader 并刷入：

```powershell
adb reboot bootloader
fastboot flash recovery_a "skyward-zeus-v6.img"
fastboot getvar slot-unbootable:a      # 期望输出 no
fastboot reboot
```

4. **先进系统，再进 recovery**（这台机器的 bootloader 不支持直接重启到 recovery）：

```powershell
# 等约 35 秒，系统起来后
adb reboot recovery
```

## 刷完自检（在 recovery 里，adb 直连就是 root）

```bash
cat /proc/uptime
ls /sys/class/net | grep wlan0          # 开机约 26 秒后出现
dmesg | grep -E "ahead of its switch|loaded aw8697|hif_enable_pci done"
```

正常表现：
- `t≈7.6s`：`loaded aw8697_haptic.bin - size: 3537`（震动固件加载成功）
- `t≈25.7s`：`wlan0` 建立
- `t≈26.1s`：`skyward: the WLAN's chip is up ahead of its switch`

## 已知行为（不是 bug）

- **WLAN 页初始是"关"**：驱动在后台预热，约 26 秒后就绪；之后点开关，1~2 秒出列表。
- 开机 26 秒内点开关，会等到接口就绪（约十几秒）——这 20 秒是 cnss2 驱动自己的死等，改不了。
- 震动：如果听到"刺啦"的尖锐声而不是干脆的"嗒"，说明固件没被加载，回来找我。

## 出问题怎么回退

- 想回官方 recovery：刷官方包里的 `recovery.img` 到 `recovery_a` 即可（系统不受影响）。
- 如果刷完进不去系统：`fastboot set_active a` 清掉 `slot-unbootable:a` 标记再重启。
- 设备没枚举：`adb kill-server; adb start-server`；仍不行就换线/换口。
